Hidden Facts Publisher

An internal tool for the YouTube channel Hidden Facts తెలుగు (@hiddenfacts_te).

Hidden Facts Publisher is a private tool used only by the owner of the Hidden Facts channel. It uses the YouTube Data API and YouTube Analytics API to upload and update the channel's own videos (title, description, thumbnail, captions, playlists) and to read the channel's own performance statistics for internal planning.

It is not offered to other users and does not access any other person's account or data.
